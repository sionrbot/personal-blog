# Triage Labels

工程技能使用以下五个规范角色。应用角色时，使用对应的仓库标签。

| 规范角色          | 仓库标签          | 含义                         |
| ----------------- | ----------------- | ---------------------------- |
| `needs-triage`    | `needs-triage`    | 等待维护者评估               |
| `needs-info`      | `needs-info`      | 等待报告者补充信息           |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交由代理自主实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施                 |
| `wontfix`         | `wontfix`         | 不予处理                     |

技能提及某个分流角色时，以本表映射为准。
如需采用已有的其他标签名称，修改“仓库标签”列。
