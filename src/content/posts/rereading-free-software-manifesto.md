## 前言

我现在每天都在用 AI 写代码。打开终端，让它读项目、改 bug、跑测试，已经是习惯了。我从来没认真想过，它读完那些文件以后，带走了什么。

今年发生的几件事让我开始想这个问题。越往下查，越觉得 Richard Stallman 四十年前担心的事，正在一件一件变成现实：平台不是我们的，软件不是我们的，服务器是大公司的，数据也是大公司的。

## 代码被传走了

7 月，有研究者抓包发现，xAI 的编程工具 Grok Build 会把用户整个 Git 仓库传到云端，包括完整的 commit 历史，也包括有人不小心提交进去的密钥。设置里有个“用数据改进模型”的开关，关掉了照样上传。AI 帮你改一个 bug，要读的是相关的几个文件，用不着整个 .git。

9 月，智谱的 ZCode 被发现做了同样的事。只要登录着，它就把整个工作区连同 Git 历史一起打包，传到阿里云 OSS。上传的东西是加密的，钥匙在智谱的服务器上，用户自己解不开，也看不到传了什么。这个功能没有开关。

两家事后都道了歉，把客户端开源了。xAI 用 Apache 2.0 发布了 Grok Build 的源码，智谱把 ZCode 放到 GitHub 上，请第三方审计。

开源客户端能让人确认以后不再上传，但回答不了之前传走的东西去了哪里。马斯克说数据会删掉，到现在也没有独立审计确认过。

## 数据离开电脑之后

编程工具只是其中一环。

平台在采集。7 月 Meta 上线了 Muse Image，公开的 Instagram 账号默认可以被别人在提示词里点名，拿他们的脸生成图片，本人不会收到通知。闹了几天，Meta 下架了这个功能。到了 9、10 月，Meta 的 Muse 助理又被曝能读用户的私信。路透社还报道，它替用户打出去的一些电话，其实是外包人员在接，事先没有告诉用户。X 上的 Grok 在 6 月被加拿大隐私专员认定违法，因为它未经同意生成真人的性化图片。

中间人在看。国内很多开发者用不了、或者用不起官方的海外模型 API，就去买中转站。中转站要转发请求，就得先把请求解开，所以你发过去的代码和提示词，它全都看得到。有人审计过几百个中转站，有的拿便宜模型冒充贵模型，有的往返回的代码里塞恶意内容，有的偷请求里的密钥。社区里一直有传言，说中转站把用户数据打包卖给模型公司做训练。这件事外人没法核实，就算真的发生了，我们也不会知道。

黑市在卖。在 Telegram 上搜“社工库”，能找到大量机器人在卖个人信息：户籍、手机号、收货地址，用 USDT 结账。这不只是国内的问题。今年 3 月，拉美的数字权利组织 Derechos Digitales 调查了巴西、秘鲁和阿根廷的 27 个 Telegram 群组和频道，发现有些在售的数据很可能来自政府数据库。

每次曝光之后，大家骂一阵，公司修一个功能，然后慢慢忘掉。计算跑在别人机器上这件事，从来没变过。

## 四十年前的警告

1985 年，Stallman 发表了《GNU 宣言》，同一年成立了自由软件基金会。他在宣言里写：“软件销售商通过让每个用户保证不和其他人分享来分化用户并控制他们。”他想要的是另一种局面：系统的源代码向每个人开放，用户想改什么，可以自己改，也可以雇别人改，“没有人再处于独断的地位”。

这些主张后来被总结成四项自由：运行软件的自由，研究它怎么工作的自由，修改它的自由，分享它的自由。说到底是一个问题：谁在控制你的计算。他有句话说得很直白：如果用户不控制程序，程序就控制用户。

他后来的文章，放到今天读更有感觉。1997 年的短篇小说《阅读的权利》，写的是一个借书给同学就算犯法、每次阅读都会被记录的未来。2010 年的《那台服务器到底为谁服务？》讲的是云：你把本该在自己电脑上做的计算交给别人的服务器，就等于交出了控制权，服务器上跑的代码就算是开源的，你也没法检查它实际做了什么、记了什么。GNU 网站上还有一个页面，标题就叫《专有软件往往是恶意软件》。它的意思是，专有软件让开发者对用户拥有权力，这种权力本身就不公正，而权力会腐蚀，开发者迟早会忍不住把程序设计得亏待用户。

Grok Build 和 ZCode 两样都占了。客户端偷偷打包上传，是他说的恶意功能。代码到了服务器以后被怎么处理，是他说的服务器问题。

## 开源赢了，自由没有

奇怪的是，开源运动其实赢了。今天的云几乎全跑在 Linux 上，大公司的产品都建立在开源软件上。可用户手里的自由，比 1985 年还少。

我觉得 Stallman 有点像自由软件运动里的 Malcolm X，Linus Torvalds 像马丁·路德·金：一个几十年不肯妥协，一个只管把代码写好，主流跟着后者走了。1998 年，Eric Raymond、Bruce Perens 这批人推出了 open source 这个说法，替代 free software，为的是让企业更容易接受：不谈自由，只谈更好的开发方式。

可自由软件和开源要的东西本来就不一样。一个要用户的自由，一个要更好的软件，开源赢下来的是后者。

这在许可证上也看得出来。GPL 的义务在分发软件时触发：你把软件给了别人，就得把源代码也给他。云服务不分发软件，只是让你用。所以一家公司完全可以拿 GPL 软件搭起整个平台，改了什么、记了什么都不用告诉你。2002 年 Affero 公司推出了 Affero GPL 来补这个漏洞，FSF 在 2007 年发布了 AGPLv3，但大多数项目选了更宽松的协议。

## 隐私的幻觉

我们平时觉得自己的隐私有保障，靠的是几样东西：设置里的开关，传输时的加密，还有出了事以后的删除。

开关是界面上的一个按钮，它背后的程序做什么，由写程序的人决定。Grok Build 的开关关了照样上传，ZCode 干脆没有开关，Muse Image 能退出，但默认开着，知道去哪里关的人很少。你按下去，只是表达了一个意愿。

加密防的是第三方，防不了拿着钥匙的那一方。ZCode 的数据是加密的，钥匙在智谱手里。HTTPS 保护的是路上这一段，到了对方的服务器就会被解开。中转站本身就是路的一头，所以它什么都看得到。

删除是对方告诉你的一个结果。数据进了服务器，会有备份，有日志，可能被拷贝到别的系统，也可能已经拿去训练了模型。模型学进去的东西，没法单独删掉。

开关、加密和删除，都在别人的机器上执行，你只能看到结果，看不到过程。

数据只要离开你的电脑，至少有三方能看到：提供服务的公司，路上的中间人，还有可以向它们调数据的政府。这三方说的话，你一句都没法验证。公司说删了，你没法查。中转站说不卖，你没法查。政府说会保管好，拉美那份调查已经说明，它的数据库一样会流到 Telegram 上。

所以靠承诺保护隐私，本身就站不住。隐私政策、道歉、开关和“已删除”，都是承诺。承诺可以改，可以写在一份没人读的条款里，也可以被一个默认打开的开关绕过去。

如果计算就在自己的电脑上跑，这些问题大多不存在。代码没离开硬盘，就不需要开关来保护它；钥匙在自己手里，加密才真的有用；想删的东西，自己就能删掉。真正的分界线，是计算在谁的机器上跑、钥匙在谁手里。

## 被拿走的是什么

说到隐私，很多人会说自己没什么好隐藏的。可让人不舒服的，是另外几件事。

一是你的行为被看着。Muse 助理读你的私信，替你打出去的电话，接电话的是你不认识的外包人员。就算最后什么事都没发生，知道这件事的那一刻，人会觉得 creepy，因为有一条边界被越过了。被看着的人也会变。知道自己被看着，就会不自觉地收着点：有些东西不搜了，有些话不说了，有些想法不写了。没有人禁止你，是你自己先缩了回去。法学里管这个叫寒蝉效应。

二是你的数据资产被拿走。我说的不是公开的网页啊，是你的私有仓库、私信和提示词。数据是一种资产。你的代码是你的劳动，里面有公司的业务逻辑，还有能直接调用付费服务的密钥。中转站如果把用户请求打包卖给模型公司，卖的就是别人的东西。Grok Build 和 ZCode 把整个仓库传上云端，没有问过你，也没有付过钱。Stallman 不喜欢“偷”这个字，因为唱片公司和软件公司一直拿它来骂分享的人。可这里方向是反过来的：不是用户复制了公司的东西，是公司没经过同意，拿走了用户的东西。这叫偷窃。

三是你的数据，被拿来对付你。数据被收集的时候，理由总是为你好：改进模型，个性化推荐，更好的服务。Grok Build 那个开关的名字就叫“用数据改进模型”。可真正用起来，方向常常是反的。同一张机票，老用户看到的价格更高，这是大数据杀熟。有报道说，Meta 的 Muse 助理把一个用户的住址给了 Marketplace 上的卖家，结果卖家找上了门。2022 年美国推翻 Roe 案以后，很多女性删掉了手机里的月经记录 App，因为里面的数据可能变成起诉她们的证据。社工库里卖的也不是什么秘密，手机号、地址、户籍拼在一起，就足够让一个人被开盒。

被看着，你还能感觉到。被偷和被用来对付你，大多数时候你根本不会知道。

## 只能选一边

监管和自由软件可以同时存在，但隐私只能押在一边：押在事后的惩罚上，还是押在事前不交出去。

第一条路是接受被托管。数据交给平台，再授权政府这个“利维坦”去管这些公司：监管它们，罚它们，向它们征税。这条路不是没用。加拿大认定 Grok 违法，Meta 下架 Muse，都是监管和舆论起了作用。可这些都发生在事后，罚款落到公司头上，被拿走的数据回不到你手里。而且政府本身也是数据的持有者，能向公司调数据，自己的数据库也会漏。走这条路，盯着你的是公司和政府两个利维坦。

第二条路是把计算拿回来，让东西一开始就不被拿走。用自由软件，尽量让计算留在自己手里：本地优先的软件，自己托管的服务，在自己机器上跑的开放模型，用 AGPL 保护服务端的项目。同时让基于自由软件的公司去取代那些非自由软件的公司。这些公司可以靠服务、支持和托管赚钱，但用户随时能带着数据走，也随时能自己跑同一套软件。用户走得掉，监管也才有底气。用户走不掉的时候，平台什么都不怕。

有些数据不得不交，户籍要交给政府，地址要交给快递。正因为交出去的迟早会漏，能留在自己手里的，就更不该交出去。

第二条路不方便。本地模型现在还比不上最强的闭源模型，自己托管要花时间，也要懂技术，自由软件用起来常常更粗糙，因为维护它的人大多拿不到报酬。可便利正是第一条路用来吸引人的东西。Muse 的方便，Grok Build 的方便，中转站的便宜，背后都是我们看不到的交换。

能做的事情不少。写代码的人，可以看看自己的 AI 编程工具到底往外发了什么，Grok Build 和 ZCode 的问题都是开发者自己抓包抓出来的；别把密钥提交进仓库，默认整个仓库都可能被传走；敏感代码不要过中转站；能在本地跑的工具，优先用本地的。不写代码的人，可以少交一点：用不着的 App 不装，能不登录就不登录，选那些允许你把数据带走的服务。

自由软件要真的能替代，还得有人养它。Open Source Pledge 让公司按每个开发者每年至少两千美元给维护者付钱，德国的 Sovereign Tech Agency 用公共资金雇人维护基础软件。个人可以给自己依赖的项目捐一点，公司能做的更多。

## 回到宣言

我想请大家重读《[GNU 宣言](https://www.gnu.org/gnu/manifesto.en.html)》。四十年前，Stallman 警告的是一个还不存在的未来，所以他看起来像个怪人。现在这个未来来了，就藏在一个默认打开的开关、一个好用的编程助手、一个便宜的中转站，和一个你没听说过的 Telegram 机器人里。
